# ООП Java — лабораторная №1

Вариант 20: «Транзакция». Платёж — это транзакция, а платёж картой — это платёж. Поэтому `PaymentTransaction` наследует `Transaction`, а `CardPaymentTransaction` наследует `PaymentTransaction`.

| Класс | Собственные поля | Собственные методы |
|---|---|---|
| `Transaction` | Идентификатор, сумма, код валюты | Увеличить сумму, уменьшить сумму, сравнить сумму и валюту |
| `PaymentTransaction` | Продавец, номер заказа, комиссия | Рассчитать списание, сверить продавца и номер заказа, проверить долю комиссии |
| `CardPaymentTransaction` | Последние четыре цифры, месяц окончания срока, признак бесконтактной оплаты | Показать маску карты, проверить срок, проверить бесконтактный лимит |

У каждого поля есть геттер и сеттер. Сумма, комиссия и лимит задаются в минимальных единицах валюты: например, 12500 для RUB — это 125 рублей. Код валюты должен быть известен Java, а её минимальная единица — определена. Сумма положительна, комиссия может быть нулевой. Списание равно сумме плюс комиссия; доля комиссии считается от суммы. Порог задаётся целым числом от 0 до 100 процентов, и равенство порогу допустимо. Карта действует до конца указанного месяца. Бесконтактный лимит сравнивается с полным списанием и не заменяет проверку срока действия.

Это редактируемые учебные записи: смена кода валюты не пересчитывает сумму, фактических списаний нет. Полный номер карты не хранится.

Из корня проекта с JDK 17 или новее:

```text
javac --release 17 -encoding UTF-8 -Xlint:all -Werror -d out lab_01/Transaction.java lab_01/PaymentTransaction.java lab_01/CardPaymentTransaction.java
java -cp out CardPaymentTransaction
```

Демонстрация выводит маску `**** 0042`, сумму списания `12750 RUB` и результат проверки лимита `true`. Если JDK не добавлен в `PATH`, укажите полные пути к `javac` и `java` из его папки `bin`.
